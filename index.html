Добро пожаловать в EDB

Модульный Discord бот с веб-панелью

EDB — это self-hosted решение для управления Discord-сервером. Бот работает в Docker, настраивается через удобный веб-интерфейс и поддерживает модульную архитектуру. Вы можете включать/выключать функции, управлять магазином с автовыдачей ролей, настраивать валюту и создавать каналы прямо из браузера.

Быстрый старт

Установка занимает 2-3 минуты. Скрипт автоматически установит все зависимости.

Шаг 1: Клонируйте репозиторий

git clone https://github.com/CerCraft/EDB.git
cd EDB

Шаг 2: Запустите установщик

chmod +x install.sh
./install.sh

Шаг 3: Откройте веб-панель

http://ВАШ_IP:3000

Скрипт автоматически установит Docker, если его нет в системе, и добавит вашего пользователя в нужную группу.

Получение токенов Discord

1. Создание приложения

  1. Перейдите на Discord Developer Portal
  2. Нажмите New Application
  3. Введите имя бота и нажмите Create

2. Получение Client ID

  1. В левом меню выберите General Information
  2. Найдите раздел Application Details
  3. Скопируйте значение APPLICATION ID

3. Получение Bot Token

  1. В левом меню выберите Bot
  2. Нажмите Reset Token (или View Token)
  3. Скопируйте появившийся токен

Никогда не публикуйте токен! Это как пароль от вашего бота.

4. Получение Guild ID

  1. В Discord откройте Настройки пользователя → Расширенные
  2. Включите Режим разработчика
  3. Кликните ПКМ по иконке вашего сервера → Копировать ID сервера

Настройка Privileged Intents

Без включения этих настроек бот не сможет работать.

  1. Откройте Discord Developer Portal
  2. Выберите ваше приложение
  3. В меню слева нажмите Bot
  4. Прокрутите вниз до Privileged Gateway Intents
  5. Включите ВСЕ ТРИ переключателя:
    • Presence Intent
    • Server Members Intent
    • Message Content Intent
  6. Нажмите Save Changes

После изменения Intents нажмите «Перезапустить» в веб-панели.

Модуль: Экономика

Модуль экономики позволяет настроить внутреннюю валюту сервера.

Настройки

Название валюты

Любое название: «Монеты», «Рубли», «Золото», «Кредиты» и т.д.

Иконка валюты

Эмодзи (🪙, 💎, 💰) или URL картинки

После изменения настроек нажмите «Перезапустить» в шапке панели.

Модуль: Магазин

Магазин позволяет продавать товары и роли за внутреннюю валюту.

Добавление товара

Название — отображается в команде /shop

Цена — стоимость в монетах

Роль — выберите из выпадающего списка ролей вашего сервера

Описание — необязательное текстовое описание

Картинка — изображение товара (необязательно)

Автовыдача ролей

Если к товару привязана роль, она автоматически выдаётся покупателю после покупки.

Важно для выдачи ролей:

  • Роль бота должна быть ВЫШЕ продаваемой роли в иерархии
  • У бота должно быть право «Управлять ролями»

Настройка прокси

Если бот не может подключиться к Discord (ошибка Connect Timeout), используйте прокси.

Шаг 1: Установите пакет

docker compose exec bot npm install https-proxy-agent

Шаг 2: Отредактируйте core/botManager.js

Добавьте импорт:

import { HttpsProxyAgent } from 'https-proxy-agent';

И передайте агент в клиент:

const proxyUrl = process.env.DISCORD_PROXY;
const agent = proxyUrl ? new HttpsProxyAgent(proxyUrl) : undefined;

bot = new Client({
    // ... настройки
    http: { agent }
});

Шаг 3: Добавьте в docker-compose.yml

environment:
  - DISCORD_PROXY=http://user:pass@ip:port

Шаг 4: Пересоберите

docker compose up -d --build

Решение проблем

Connect Timeout Error

Бот не может подключиться к Discord API.

Решение 1: Смените DNS:

echo "nameserver 1.1.1.1" | sudo tee /etc/resolv.conf

Решение 2: Используйте прокси (см. раздел выше)

Решение 3: Смените хостинг на зарубежный

Бот не выдаёт роли

• Роль бота должна быть ВЫШЕ продаваемой роли

• У бота должно быть право «Управлять ролями»

• Проверьте, что в Developer Portal включены все Intents

Веб-панель не открывается

Откройте порт 3000 в firewall:

sudo ufw allow 3000/tcp

Проверьте, что контейнер запущен:

docker ps

Ошибка токена

• Убедитесь, что токен скопирован без пробелов

• Включены все Privileged Intents

• Бот приглашён на сервер с правами Administrator
